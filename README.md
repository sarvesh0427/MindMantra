# 🧠 MindMantra v2

MindMantra v2 is an AI-powered mental health screening and support platform designed to provide early mental health assessment through intelligent symptom analysis, and personalized recommendations.

Building upon the first version - a Final Year Project, MindMantra v2 introduces a scalable backend architecture, improved prediction capabilities, and enhanced user experience.

## 🚀 Key Improvements

* ⚡ FastAPI-powered backend for high-performance API services
* 🗄️ PostgreSQL database integration for secure data management
* 🤖 Advanced NLP techniques for symptom understanding and chatbot interactions
* 🧠 Mental health condition prediction using Machine Learning
* 💬 Intelligent conversational support system
* 📊 Improved model performance and scalability
* 🔒 Enhanced security and maintainable system architecture

## 🛠️ Tech Stack

* Python
* FastAPI
* PostgreSQL
* Machine Learning
* Natural Language Processing (NLP)
* Streamlit (Frontend Integration)
* Docker
